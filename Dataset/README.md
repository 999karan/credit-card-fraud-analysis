# Dataset

The data files are too large for GitHub (over 100 MB), so they are not stored here.

1. Download `creditcard.csv` from the Kaggle **Credit Card Fraud Detection** dataset and place it in this folder.
2. Load it into MySQL using `../SQL/Database_Setup.sql`.
3. Run `../Python/extract_and_clean.py` to regenerate `transactions_cleaned.csv`.
